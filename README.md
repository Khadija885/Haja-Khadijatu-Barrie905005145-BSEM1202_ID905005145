# PikinCare SL

## Pediatric Healthcare Website

PikinCare SL is a responsive pediatric healthcare landing page developed to improve access to child healthcare information and services in Sierra Leone.

The website was designed as a Digital Public Good (DPG) project aligned with Sustainable Development Goal 3: Good Health and Well-being.

---

# Project Overview

Many parents and guardians in Sierra Leone experience challenges accessing quality pediatric healthcare services and information.

PikinCare SL provides a digital healthcare platform that helps families learn about pediatric services, child wellness, vaccinations, and healthcare support through a simple and responsive website.

---

# Features

- Responsive website design
- Modern pediatric healthcare landing page
- Hero section with call-to-action buttons
- Services section
- About section
- Contact section
- Mobile-friendly layout
- Desktop, tablet, and mobile responsiveness
